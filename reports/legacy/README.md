# Wyniki historyczne

Przeniesione bez przeliczania z `models_results`, `main_model/results` i
`selected_features`. Zawierają wyniki dawnej metodologii z błędami opisanymi
w `docs/AUDIT.md`; nie potwierdzają przewagi modelu nad benchmarkiem.
Historyczne wykresy korelacji są w `figures`.

Nowy CLI zapisuje odrębne eksperymenty w `reports/runs`, wraz z konfiguracją,
wersjami zależności, hashem danych, rzeczywistymi licznościami foldów,
wybranymi cechami i prognozami. Nie nadpisuje raportów historycznych.
